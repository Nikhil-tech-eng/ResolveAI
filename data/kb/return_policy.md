# Return Policy

1. Look up the order and verify that its recorded status is delivered and that a delivery date is available.
2. Calculate the return window from the delivery date. Returns are allowed through 30 days after delivery; a request after that window must not be accepted automatically.
3. Explain an ineligible request using the verified delivery date and escalate if the customer disputes the policy decision.
4. For an eligible request, create the return request and generate a label only after the policy check succeeds.
5. Premium customers receive free return shipping. Apply the standard return-shipping fee for other tiers and state the amount returned by the tool.
