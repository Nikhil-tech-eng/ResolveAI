# SLA and Response Times

1. Verify the customer's tier before communicating a service-level target.
2. Use a 15-minute response target for premium customers and a 60-minute response target for standard customers.
3. Describe these values as response targets, not guaranteed resolution or refund-settlement times.
4. Check the ticket deadline and current status when available; flag an at-risk SLA for escalation.
5. If a target has been missed or the deadline is unknown, acknowledge the delay and route the case according to the escalation policy.
