# Premium Customer Benefits

1. Verify the customer's tier using the customer profile; do not infer premium status from a message or order value.
2. For an eligible premium customer, return shipping is free.
3. Premium tickets have a 15-minute service-level target for response; this is a response target, not a guaranteed resolution time.
4. Apply the same order, payment, return-window, and account-security policy checks that apply to other customers.
5. Explain only benefits supported by the account records and current policy; escalate questions about unlisted benefits.
